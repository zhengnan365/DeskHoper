# 更新日志

版本号写在 `DeskHoper.csproj` 的 `<Version>`，每个发布打同名 git tag，发布物挂在 GitHub Releases 上。

## v2.2.1

2026-10-23

只换图标，程序功能、协议和配置格式与 v2.2.0 完全一致。

- 应用图标重做：旧版是描边式的两屏 + 支架 + 绿色箭头，缩到托盘那个 16px 时边框和箭头全部糊掉；新版改成蓝底 + 两块实心白屏 + 白色切换箭头，在 48 / 32 / 24 / 16 四档下逐档实拍确认过仍可辨认

## v2.2.0

2026-10-23

一台台式机和一台笔记本共用同一套外接显示器、键盘和鼠标。这个版本补完了两台机器之间的共享链路：鼠标转发跟手了、文件收发有进度、地址只认物理网卡，另外加上了托盘。

### 新增

- **键鼠共享**：三张卡片选角色，控制端和被控端自动镜像，不用两台各点一次；键盘和鼠标可以分开共享；`Ctrl + Alt + Q` 随时交回本机
- **文件传输进度**：等待对端接收 → 发送中 / 接收中百分比 → 带文件数和总量的终态，停 8 秒后自动收回
- **托盘**：点关闭时选「隐藏到托盘」或「退出程序」，选一次就记住；藏进托盘时剪贴板同步、文件共享、键鼠转发和全局热键照常工作
- **单实例唤回**：程序已经在运行时再双击 exe，只把已有窗口唤回前台，不会开出第二个
- **局域网发现**：同网段的对端自动出现在「我连接对方」列表里，点一下就填好名称和地址

### 修复

- **共享鼠标时指针乱跳**：改用系统原始输入取真实位移。之前用光标坐标做差值，在多屏加 175% DPI 的坐标换算下必然跳
- **本机地址抓错网段**：Tailscale、Hyper-V、VMware 这类虚拟网卡不再被当成本机地址，发现层的收发只走有线和无线物理网卡
- **鼠标拖拽感**：关掉 Nagle、小帧合并成一次写、发送改成串行等待
- 共享页发现设备后窗口底部被裁切；连接状态行不居中；三页字号不统一

### 注意

- 第一次启动会明显慢：实测同一份包，首次从双击到首屏就绪约 23 秒，第二次 1.7 秒。这是 Windows 首次读取并扫描 138 MB 单文件 exe 的代价
- 端口没变：TCP `47810`、UDP `47811`，防火墙要放行「专用网络」
- 从旧版升级：整个文件夹覆盖即可，配置目录 `DeskHoper-config` 沿用
