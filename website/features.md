# 功能特性

DeskHoper 管三件事：外接屏切给谁看、文件怎么过去、键盘鼠标归谁敲。三件互相独立，可以只用屏幕切换，也可以只用文件共享。

## 屏幕切换

### 快速切换

两张卡片对应两套接线，比如「台式机」和「笔记本」。点一下，程序按**每台显示器分别**切到这张卡片记录的输入源——两屏接的是同一组线，还是各接一路，都能一次切完。当前生效的那张卡片有蓝框和绿点。

卡片名字双击进入「编辑输入源和投影模式」，可以改这台卡片下每台显示器切到哪个口、以及切完之后用哪种投影模式。

### 投影模式

仅电脑屏幕 / 复制 / 扩展 / 仅第二屏幕，四个状态一个按钮。它改的是 Windows 的显示拓扑，和上面的输入源是两件事，可以分别用。

### 显示器控制

逐台读取当前输入源，可以单独把某一台切到 DP、Type-C 或 HDMI。

- **学习输入源**：换了接线、或者显示器型号不在内置映射里，点它重新认一遍。学习结果按每台显示器独立保存。
- **标识**：让屏幕闪编号，方便对上「显示器控制」列表里那行是哪块屏。
- 显示器名字双击可改。

不同品牌型号的显示器，DDC/CI 的 Input Select（VCP 0x60）取值并不一样。DeskHoper 不要求所有显示器用同一套值：你学出来的值优先于内置的默认映射。

## 文件共享

![文件共享页](/images/file-share.png)

### 剪贴板文本

复制即同步，不用点任何东西。文本双向走，对面直接粘。

### 传文件

**把文件拖进拖放区才发送。** 本机自己复制文件不会触发发送——复制文件和本机拷一份在剪贴板层面分不出来，「复制即发」必然误发。

- 收到的文件写进你指定的接收目录，同时写进本机剪贴板，可以直接粘进资源管理器。
- 收发都有进度：等待对端接收 → 发送中 / 接收中百分比 → 带文件数和总量的终态，停 8 秒后自动收回。
- 同名不覆盖，只往接收目录里写新文件名。
- 单次上限 200 个文件、总量 512 MB。

## 键鼠共享

![键鼠共享页](/images/keyboard-mouse.png)

三张卡片，选哪张就等于选角色：

| 卡片 | 含义 |
| --- | --- |
| 各用各的键鼠 | 不拦截、不转发，两边互不影响 |
| 共用本端键鼠 | 这台当控制端，敲的键和滑的鼠标送到对面 |
| 共用远端键鼠 | 这台被控，接收对面的键鼠 |

在一台换卡片，对面会自动镜像成互补的那张，不用两台各点一次。键盘和鼠标是两个独立勾选，可以只共享鼠标。

鼠标位移取自系统原始输入（raw input），不受 DPI 和多屏坐标换算影响；`Ctrl + Alt + Q` 随时把键鼠交回本机。

## 托盘与单实例

- 点关闭会让你选「隐藏到托盘」还是「退出程序」，选一次就记住。隐藏到托盘时窗口只是收起来，剪贴板同步、文件共享、键鼠转发和全局热键全部照常工作；退出才是真的全停。
- 托盘图标单击唤回窗口，右键菜单有切换到台式机 / 切换到笔记本 / 打开主界面 / 退出。
- 已经在跑（包括藏在托盘里）时再双击 exe，会把那个实例的窗口唤回前台，不会开出第二个。

## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl + Alt + 1` | 切到台式机场景 |
| `Ctrl + Alt + 2` | 切到笔记本场景 |
| `Ctrl + Alt + Q` | 交回键盘鼠标 |

## 配置文件

配置保存在 exe 旁边的 `DeskHoper-config` 目录，由程序首次运行时创建。删掉对应文件即可恢复该项配置。

| 文件 / 目录 | 内容 |
| --- | --- |
| `profiles.json` | 切换场景（每台显示器的输入源 + 投影模式） |
| `monitors.json` | 每台显示器的输入映射、自定义名称、排序 |
| `settings.json` | 输入源默认映射、关闭时的行为等应用设置 |
| `peer.json` | 本机名称、已信任的对端指纹、接收目录、键鼠模式 |
| `接收文件/` | 默认接收目录，可由 `peer.json` 里的 `ReceiveDirectory` 改走 |
| `logs/` | 运行日志 `deskhoper-YYYYMMDD.log` |
