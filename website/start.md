# 快速开始

## 下载与启动

1. 到 [Releases](https://github.com/zhengnan365/DeskHoper/releases/latest) 下载 `DeskHoper-vX.Y.Z-win-x64.zip`。
2. **整个文件夹解压出来**，不要只拷 `DeskHoper.exe`——旁边有 5 个 WPF 原生 dll 必须一起带上。
3. 双击 `DeskHoper.exe`。self-contained 包，目标机不需要安装 .NET Runtime。
4. 首次监听网络时 Windows 会弹防火墙授权，**两台机器都要勾选「专用网络」**，否则局域网发现列表是空的、手填 IP 也连不上。

**第一次双击会比以后慢很多。** 实测同一份包，首次从双击到首屏就绪约 23 秒，第二次只要 1.7 秒。这 20 秒花在 Windows 首次读取并扫描这个 138 MB 的单文件 exe 上（包体不会解压到临时目录），不是程序卡住，别连点。

程序没有安装步骤，不写注册表，不开机自启，没有后台服务。关掉程序 = 所有共享能力立即停止。

## 配对

![配对](/images/pairing.png)

两台机器要互相认识一次，之后记住指纹直连。

1. 两台都打开 DeskHoper，停在**文件共享**页。局域网发现只在停着的时候收发广播，别的页面上不收不发。
2. 一台点「生成配对码」，屏幕显示 6 位数字，5 分钟内有效。
3. 另一台在「我连接对方」里点它——同网段会自动出现在列表里，点一下就填好地址；也可以手填名称或 IP，然后输配对码。
4. 连上后配对这块自动收起，需要重新配对时断开即可。

配对码是首次信任（TOFU）的一环：发现列表被伪造最多是多出一条假设备，连过去仍然必须输对码。

## 只用屏幕切换的话

不需要配对，也不需要第二台机器开着。装好就能用：

- 先在**屏幕切换**页点「学习输入源」，让程序认一遍每台显示器的输入口取值。
- 然后把两套接线分别存进两张卡片：双击卡片名字，逐台选好输入源和投影模式。
- 以后换机器就点卡片，或者用 `Ctrl + Alt + 1` / `Ctrl + Alt + 2`。

## 升级与回退

- 升级：下载新的 zip，**整个文件夹覆盖**旧的即可，配置目录 `DeskHoper-config` 沿用，配对关系不用重做。
- 回退：把旧版本的 zip 解压到另一个文件夹，直接跑那个 exe。配置目录跟着 exe 走，同目录下留着就还在。
- 彻底清干净：退出程序，删掉 exe 旁边的 `DeskHoper-config` 目录。日志、已信任指纹、学习出来的输入映射都在里面，删了就恢复默认。
